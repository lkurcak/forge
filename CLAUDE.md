# forge: notes for agents

## Backlog

Work is tracked in `BACKLOG.md`: `## Now` (in order), `## Later`, `## Done`, one list item
each. An item that needs more than a line or two links to its details file
(`- [Title](backlog/title.md)`), which is deleted when the item is done.

Keep it current: move what you finished to Done in the same change, and put new ideas under
Later instead of leaving them in the chat. Don't invent items.
